# TaskFlow

![CI](https://github.com/MechatronicCoder/taskflow/actions/workflows/ci.yml/badge.svg)

Gestor de tareas en Python · Proyecto integrador del curso **DevOps & Project Management**.

## Equipo
- William Fabian Huaman Huaman — @MechatronicCoder

## ¿Qué hace?
TaskFlow permite agregar tareas con prioridad (baja, media, alta), completarlas y listar las pendientes.

## Cómo ejecutarlo
```bash
python -m venv .venv
source .venv/bin/activate        # Windows (Git Bash): source .venv/Scripts/activate
pip install -r requirements.txt
python -m taskflow
python -m pytest -v
```
